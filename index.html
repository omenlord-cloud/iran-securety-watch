مرکز اخبار

خبرها از فیدهای عمومی دریافت می‌شوند؛ ممکن است بعضی منابع در دسترس نباشند. ساعت‌ها به وقت تهران است.

در حال تلاش برای دریافت اخبار عمومی...
زمان نمایش‌داده‌شده، زمان انتشار خبر توسط منبع است. اگر منبع زمان انتشار نداده باشد، «زمان انتشار نامشخص» نوشته می‌شود و خبر در انتهای فهرست می‌آید. برای تصمیم‌های حساس، متن اصلی خبر و اطلاعیه‌های رسمی را بررسی کنید.

مرکز تحلیل هوشمند

خلاصه‌سازی ساده بر اساس خبرهای دریافت‌شده؛ بدون اتصال به مدل هوش مصنوعی خارجی.

تحلیل محتوای موجود نسخه بدون API

با انتخاب دکمه زیر، صفحه موضوعات پرتکرار در خبرهای فعلی را استخراج می‌کند. این قابلیت تحلیل نظامی یا پیش‌بینی حمله نیست.

برای شروع تحلیل، دکمه بالا را انتخاب کنید.
برای تحلیل واقعی با هوش مصنوعی، باید API معتبر از طریق سرور امن متصل شود؛ کلید API را داخل HTML عمومی قرار ندهید.
